# Profile Engine

## Tujuan
Mengelola identitas permanen pengguna.

## Intent

### CREATE
Pengguna memperkenalkan dirinya.

Contoh:
- Namaku Hiban
- Nama saya Hiban
- Aku bernama Hiban

### SHOW
Pengguna menanyakan identitasnya.

Contoh:
- Siapa aku?
- Apa namaku?
- Namaku siapa?

### UPDATE
Pengguna ingin mengganti identitas.

Contoh:
- Ganti namaku menjadi Budi
- Panggil aku Alex mulai sekarang

### UNKNOWN
Bukan intent profile.
